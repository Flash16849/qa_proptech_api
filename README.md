# API Testing & Test Management Showcase

This repository serves as a practical showcase of my transition from Software Development to Quality Assurance. Through this project, I have applied and refined my QA mindset, built a structured test case management workflow, and implemented hands-on API testing.


## Tech Stack & Tools

- **Test Management:** Jira, Zephyr Scale
- **API Testing:** Postman (Dynamic variables, Request chaining)
- **Defect Tracking:** Jira Bug Tracking
- **Version Control:** GitHub


## Test Case Design
Over 30+ test cases designed and structured within Zephyr Scale. Test cases utilize dynamic parameters like {id} and {base_url} to ensure high reusability and maintainability.

## Requirements Traceability & Defect Tracking
All test cases are mapped directly to Agile requirements (**Jira User Stories**) to ensure full coverage.
Additionally, **all 7 defects discovered during testing are logged and tracked** directly on the Jira Kanban Board to maintain software quality.
